# CivicOS five-minute script

**0:00** Cities often react after a disruption. CivicOS turns a simulated rainfall report into an operational decision trail.

**0:40** Log in as a municipal officer and submit the clearly labelled synthetic drain-blockage report. Explain validation and conservative duplicate matching.

**1:20** Show weather context, GIS enrichment, risk drivers, and relationship graph. Clarify that predictions are trained from synthetic reference data.

**2:10** Run the cascade view: it is a deterministic simulation, not a live observation; read the causal chain and prevention break.

**3:10** Show the department recommendation and generated work order. Assign a team, start work, and record supervisor evidence.

**4:10** Show resolved incident history, session-backed authorization, and SQLite persistence. CivicOS links intelligence to accountable action.
